# AI Power Tools for Microsoft Visio - Skills

Skills for **AI Power Tools for Microsoft Visio**, the MCP server that drives Microsoft Visio.

This branch, `main`, holds **released skills only**. It is updated only when a release is cut.
Development happens on the `dev` branch, in feature branches taken from it. Nothing is installed
from `dev`.

No skills have been released yet.
